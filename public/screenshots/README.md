# Screenshots

Place screenshot images in this directory for use in the README.

Expected files:

- `home-grid.png` — Home page in grid view
- `home-list.png` — Home page in list view
- `file-preview.png` — File preview (e.g., Markdown or image)
- `raw-view.png` — Raw/plain text view of a code or Markdown file

These paths are referenced in `README.md` and `README.vi-VN.md`.
